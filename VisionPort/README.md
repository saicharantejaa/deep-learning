# VisionPort

Intelligent Vehicle Detection and Traffic Monitoring System.

This folder keeps the project tasks separate. Each task should be implemented, tested, and committed independently.

## Tasks

1. Environment Setup
2. Camera Capture
3. Image Display
4. Video Playback
5. Frame Extraction
6. Vehicle Detection
7. Vehicle Classification
8. Confidence Scores
9. Vehicle Counting
10. Traffic Density
11. Congestion Detection
12. Vehicle Tracking
13. Speed Estimation
14. Traffic Signal Detection
15. Waiting Time Estimation

> Task names are an initial structure and should be checked against the task list provided by the instructor.
