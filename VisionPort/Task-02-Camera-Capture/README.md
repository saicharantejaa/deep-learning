# Task 02 – Camera Capture

**Objective:** Capture an image of a traffic signal or traffic scene using a webcam.

**File:** `capture_traffic_image.py`

**Run (PowerShell):**

```powershell
py -m pip install opencv-python
py capture_traffic_image.py
```

Point the camera at a traffic signal or road scene. Press **S** to save `traffic_image.jpg` in the current folder. Press **Q** to close the camera.

**Expected output:** A saved traffic image named `traffic_image.jpg`.

**Note:** The camera must be connected and permitted by Windows. Close other apps that may be using it if it does not open.
