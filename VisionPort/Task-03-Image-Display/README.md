# Task 03 – Image Display

**Objective:** Read a traffic image and display it using OpenCV.

**File:** `display_traffic_image.py`

**Run:**

```powershell
py display_traffic_image.py
```

When asked, enter an image path, for example `traffic_image.jpg` or `D:\Photos\traffic.jpg`. Press any key while the image window is active to close it.

**Expected output:** OpenCV displays the selected traffic image and prints its width and height.
