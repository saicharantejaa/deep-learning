# Task 08 – Vehicle Names and Confidence Scores

**Objective:** Display the detected vehicle name and YOLO confidence score.

**File:** `show_confidence_scores.py`

**Run:**

```powershell
py show_confidence_scores.py
```

Enter a traffic video path. The preview shows each detection's class label and confidence. The terminal also prints the vehicle name and confidence value (from `0` to `1`) for each detection.

**Expected output:** Labelled bounding boxes, confidence values in the terminal, and an annotated video under `outputs/confidence_scores/`.
