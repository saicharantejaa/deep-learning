# Task 04 – Video Playback

**Objective:** Load and play a traffic video using OpenCV.

**File:** `play_traffic_video.py`

**Run:**

```powershell
py play_traffic_video.py
```

Enter the path to an MP4/AVI video. Press **Q** in the video window to stop playback.

**Expected output:** The traffic video plays in an OpenCV window.
