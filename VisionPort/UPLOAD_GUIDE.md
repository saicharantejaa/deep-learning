# GitHub upload guide

This package contains the contents for the existing `VisionPort/` folder in the `saicharantejaa/deep-learning` repository.

1. Extract this ZIP into the local clone's `deep-learning` directory. Merge the included `VisionPort` folder with the existing one.
2. Do not replace or delete the repository's `.git` folder.
3. Review the files with `git status`.
4. Run and verify each task before committing it.
5. Commit each task separately, as instructed by your teacher.

Task 01 is intentionally omitted. Tasks 02-20 are included. No captured evidence, input videos, or YOLO weights are included; add genuine output evidence only after you generate it.
